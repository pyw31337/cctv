# 실제 브라우저 재생 카나리 운영 결정

## 결정

실제 Chromium 브라우저로 재생 시작 여부를 확인하는 카나리는 `workflow_dispatch` 수동 실행으로 둡니다. GitHub Actions 분 단위가 이미 민감하기 때문에 10분/30분 주기 자동 실행은 지금 단계에서 기본값으로 두지 않습니다.

## 운영 기준

- 기본 품질 판단은 Oracle 15-30분 카나리, Z3 캐시 최신성, 사용자 실사용 텔레메트리를 합쳐 판단합니다.
- 녹색 신뢰도는 서버 URL 응답만으로 확정하지 않고, 실사용 성공 또는 수동 브라우저 카나리 성공 이력이 있을 때 강화합니다.
- 진도, 제주, 대전, 구리, 남양주, 독도에서 반복 민원이 있거나 공급처 구조가 바뀐 것으로 보이면 `Manual Browser Playback Canary`를 수동 실행합니다.
- 브라우저 카나리 실패는 카메라 삭제 사유가 아니라 후순위/운영 점검 사유입니다.

## 유료 인프라를 쓰는 경우

브라우저 카나리를 10-30분 주기로 자동화하려면 GitHub Actions가 아니라 작은 유료 VM 또는 Cloudflare Browser Rendering/Workers 조합을 검토합니다. 무료 유지 기준에서는 서버 카나리와 사용자 텔레메트리를 우선합니다.
